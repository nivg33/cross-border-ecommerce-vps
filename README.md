平台靠 IP 判断账号归属，同一个 IP 跑两个店，等于自己告诉平台这两个账号是一伙的。5 个店就 5 台机器，或者一台机器配多个独立 IP。SixtyNet 住宅系列每台自带一个住宅 IP，多店只能多开机器。

## “双 ISP”到底指什么，别被营销词带偏

这个词在市面上有两种用法，含义差得挺远。

一种说法是 IP 本身同时挂着两个运营商的归属标注，纯净度更高，被判定成代理的概率更低。跨境电商圈里普遍是这么用的，SixtyNet 的 Cox 线路在 IP 归属查询里显示为双 ISP 属性，属于这一种。

另一种说法来自 SurferCloud 2024 年 11 月的官方博客：Dual ISP 指提供两个不同 ISP 的 IP 地址，做的是冗余，一条线路出问题另一条接管，减少宕机时间。

前者讲一个 IP 的属性，后者讲两个 IP 的高可用，不是一回事。看到“双 ISP”三个字，先问一句是哪种，再谈价格。

自己验证的办法很朴素：拿到 IP 丢进归属查询工具，看结果是住宅还是标着 Hosting。标 Hosting 就是机房 IP，文案写得再漂亮也改不了这个结果。也正因为这样，用线路参数和 ping 值判断 IP 质量，方向从头就是错的，100ms 的干净住宅线路比 50ms 的数据中心 IP 有用得多。
